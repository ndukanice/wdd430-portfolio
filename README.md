# WDD 430 Portfolio

A personal portfolio site built with Next.js (App Router), TypeScript and Tailwind CSS.

## Live Site

https://wdd430-portfolio-ucmv.vercel.app/

## Pages

- `/` – Home page listing portfolio projects
- `/about` – About page with skill cards
- `/api/hello` – Simple API route returning JSON

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `app/` – routes, layout and global styles
- `components/` – reusable Server Components (`Header`, `Footer`, `ProjectCard`, `ProjectList`, `SkillCard`)
- `public/` – static assets
